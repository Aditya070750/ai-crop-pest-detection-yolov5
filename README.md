# AI-Based Crop Pest Detection Using YOLOv5

An AI-based computer vision system for detecting crop-damaging pests using YOLOv5 and Python.

## Overview

This project uses the YOLOv5 object detection model to identify different types of pests from images. The system was developed to support early pest identification and help improve crop protection.

## Pest Classes

The model detects five pest classes:

- Cockroach
- Mouse
- Aphid
- Whitefly
- Locust

## Technologies Used

- Python
- YOLOv5
- PyTorch
- OpenCV
- Computer Vision
- Machine Learning

## Features

- Real-time pest detection
- Bounding-box based object detection
- Detection of multiple pest classes
- Custom-trained dataset
- Image-based pest identification

## Project Workflow

1. Collect and prepare pest images.
2. Annotate the dataset for object detection.
3. Train the YOLOv5 model.
4. Validate the trained model.
5. Run pest detection on new images.
6. Display detected pests with bounding boxes.

## Applications

- Crop pest monitoring
- Early pest identification
- Smart agriculture
- Precision agriculture
- AI-assisted crop protection

## Future Scope

The system can be further improved by adding more pest classes, deploying the model on edge devices, and integrating it with a smart agriculture monitoring system.
